# 像素风中英文字体与全站缩放设计

## 目标

在保留现有强像素游戏风格的前提下，统一网站的中英文字体视觉大小，并在顶部导航栏增加可调节全站文字大小的按钮和滑块。

本次工作优先在 `D:\PersonalSite` 本地实现、测试并使用本地 Git 记录版本。只有用户明确要求“提交同步 GitHub”时才允许推送远程仓库。

## 现状与问题

网站目前同时使用 Zpix、Press Start 2P、VT323 和 Fira Code。不同字体即使设置相同的 CSS 字号，字面高度、基线和留白也不同，因此中英文放在一起时会出现肉眼可见的大小差异。

项目标题已经有中文、英文分别渲染和视觉倍率的局部实现，但该规则尚未覆盖全站，其他模块仍存在散落的像素字号。

## 字体架构

### 实际字体

- 中文像素字体：Zpix。
- 英文展示字体：Press Start 2P，用于页面标题、区块标题、按钮和状态等强调内容。
- 英文正文与辅助信息：VT323，用于说明文字和可读性优先的内容。
- 终端与代码：Fira Code。
- 每类字体保留合适的 `monospace` 回退字体，避免自定义字体加载失败时文字不可读。

### 语义字号

将现有分散在各选择器中的像素字号整理为可复用的语义变量，至少覆盖：

- 页面大标题。
- 区块标题。
- 卡片标题。
- 正文。
- 导航与按钮。
- 状态与技术标签。
- 终端文字。

所有需要跟随全站缩放的字号使用 `rem` 或由 `rem` 派生的语义变量。头像、Emoji、图片、边框、阴影和粒子背景继续使用独立尺寸，不跟随字体缩放。

### 中英文混排

中英文混排内容使用明确的语言片段，不依赖自动字符识别：

```html
<span class="text-mixed">
  <span lang="zh-CN" class="text-cn">中文标题</span>
  <span lang="en" class="text-en-display">English Title</span>
</span>
```

- 中文和英文分别应用对应字体及视觉倍率。
- 容器使用基线对齐，并通过统一变量控制行高和间距。
- 倍率通过 `font-size: calc(...)` 影响正常排版尺寸，不使用 `transform: scale()`，避免文字看似缩放但布局占位没有变化。
- 现有项目数据继续支持分开的 `title` 和 `titleEn` 字段；纯中文或纯英文内容不创建空语言片段。
- 数字、标点和 Emoji 由内容作者放入语义上所属的语言片段，避免自动分类产生不稳定结果。

## 顶部字体缩放控件

### 外观与位置

- 在顶部导航栏增加一个像素风按钮，按钮文字显示当前比例，例如 `A 100%`。
- 点击按钮展开一个与现有网站配色一致的小面板。
- 面板包含“字体大小”、当前百分比和原生范围滑块。
- 控件沿用网站的像素边框、阴影、字体和焦点样式，不引入新的 UI 库。

### 调节规则

- 滑块范围：90%～130%。
- 步长：5%。
- 默认值：100%。
- 拖动滑块时全站文字实时更新，按钮与面板中的百分比同步变化。
- 点击控件外部或按 `Escape` 关闭面板。
- 再次点击按钮可主动收起面板。

### 状态保存

- 使用浏览器 `localStorage` 保存字号比例，键名固定为 `personal-site-font-scale`。
- 页面初始化时读取保存值；仅接受 90～130 之间且为 5 的整数倍的数值。
- 保存值缺失、格式错误或越界时恢复到 100%。
- JavaScript 不可用或初始化失败时，CSS 默认值保证网站仍以 100% 正常显示。

### 缩放实现

根元素通过一个明确的状态属性控制基础字号，例如：

```html
<html data-font-scale="100">
```

CSS 为 90、95、100、105、110、115、120、125、130 九个合法状态设置基础字号。全站语义字号使用 `rem`，因此会按相同比例变化，同时保留标题、正文、中文和英文之间既定的相对关系。

不使用浏览器页面缩放，也不整体缩放页面容器，以免图片模糊、边框变形或交互坐标异常。

## 组件与数据流

新增一个独立的字体缩放初始化函数，职责仅包括：

1. 查找按钮、面板、滑块和比例标签。
2. 从本地存储读取并校验初始值。
3. 把合法比例写入根元素的 `data-font-scale`。
4. 同步按钮文字、滑块值和面板比例。
5. 处理按钮点击、滑块输入、点击外部和 `Escape` 键。
6. 将合法的新值写入本地存储。

字体渲染规则留在 CSS，交互状态留在 JavaScript，项目和个人内容继续留在 `data.js`，不改变现有数据维护方式。

## 页面覆盖范围

下列文字必须接入语义字号和全站缩放：

- 顶部品牌、导航链接和字体按钮。
- 首页标题、身份、副标题、说明和滚动提示。
- ABOUT 标题、介绍、属性和技能标签。
- PROJECTS 标题、项目卡片标题、说明、状态和技术标签。
- RESUME 标题、时间、经历标题、公司、说明和标签。
- TERMINAL 标题、正文、输入框和小游戏文字中由 CSS 控制的部分。
- 页脚文字。

Canvas 内直接绘制的小游戏文字不纳入本次全站缩放，因为其字号由 Canvas 绘图代码和固定画布尺寸共同决定；调整它会扩大任务范围并影响游戏布局。

## 响应式与可访问性

- 导航栏继续允许换行；字体控件不得遮挡现有导航链接。
- 在手机宽度和 130% 字号下，控件面板必须保持在视口内。
- 按钮使用 `aria-expanded` 和 `aria-controls` 表达面板状态。
- 滑块提供可读标签、当前百分比和合理的键盘操作。
- 面板关闭后不强制移动用户焦点；按 `Escape` 从面板内关闭时，焦点返回触发按钮。
- 保留清晰的 `:focus-visible` 样式。
- 使用 `lang="zh-CN"` 与 `lang="en"` 标记混排片段，帮助浏览器和辅助技术理解语言。

## 验收与测试

### 自动检查

- HTML、CSS 和 JavaScript 静态检查无语法错误。
- 字体比例只允许九个合法等级。
- 无保存值、合法保存值、非法保存值分别得到 100%、保存值和 100%。
- 滑块输入会同时更新根元素属性、按钮文字、面板比例和本地存储。
- 现有项目整卡新标签页跳转、导航滚动和终端交互不受影响。

### 浏览器检查

分别在 90%、100%、130% 三个代表性等级检查桌面和手机宽度：

- 中英混排的视觉高度协调、基线稳定。
- 导航允许合理换行，但无重叠和遮挡。
- 卡片标题、说明、状态与标签无裁切。
- 时间线、终端和页脚无文字溢出。
- 滑块可用鼠标和键盘操作。
- 刷新页面后恢复上次选择。
- 点击外部和按 `Escape` 均能关闭面板。

## 非目标

- 不更换现有像素字体或改变网站整体视觉风格。
- 不缩放图片、Emoji、边框、阴影和粒子背景。
- 不调整 Canvas 小游戏内部字体。
- 不引入前端框架、组件库或第三方缩放依赖。
- 不在本次工作中同步 GitHub。
