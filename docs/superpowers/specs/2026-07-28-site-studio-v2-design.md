# PersonalSite 可视化编辑工作台 V2 设计说明

## 目标

把当前按“整块区域”调整排版、在页面原地输入文字的临时工作台，升级为按“每条可见文字”独立编辑的本地可视化工作台。岁安可以在固定侧栏中修改文案、选择字体和调整字号，并在页面中即时看到结果；也可以点击页面上的任意可编辑文字，让侧栏自动定位到对应编辑项。

工作台仍服务于本地定稿过程。定稿前，草稿只保存在浏览器中；定稿后再执行一次独立维护，把确认值写回网站源文件并移除临时工作台。

## 范围与约束

- 只修改 `D:\PersonalSite`，允许创建本地 Git 提交，但不推送 GitHub。
- 保留现有强烈的像素游戏视觉风格及中英文混排适配。
- 覆盖导航、Hero、About、Projects、Resume、Terminal 和页脚中所有带稳定编辑键的可见文字。
- 图片、Emoji、Canvas、边框、间距和其他非文字视觉元素不参与字号缩放。
- 项目卡片跳转、导航滚动、终端命令、人物状态切换和小游戏在退出编辑状态后必须保持原行为。
- 终端小游戏速度不加入工作台控制；其固定配置为初始速度 `1`、最高速度 `2.5`。

## 核心交互

### 打开与关闭

- 点击页面上的“编辑网站”按钮进入编辑状态并打开右侧侧栏。
- 编辑状态下，侧栏保持常驻。点击页面空白、滚动页面、切换折叠模块或按 `Escape` 都不得关闭侧栏。
- 只有点击侧栏右上角的 `×` 才会退出编辑状态并关闭侧栏。
- 关闭后焦点返回“编辑网站”按钮，页面上的导航、链接、卡片和终端恢复正常交互。
- 再次打开时保留此前的折叠状态和当前选中项；若选中项已不存在，则回到侧栏顶部。

### 侧栏结构

侧栏按网站区域分组，继续使用可折叠模块：导航、Hero、About、Projects、Resume、Terminal、页脚。模块只负责组织文字，不再提供统一的字体或字号设置。

每个模块内列出该区域的所有可编辑文字。每条文字使用简短、可理解的中文名称，例如：

- Hero：姓名、身份介绍、个人简介、下滑提示。
- About：模块标题、介绍、属性面板标题、各属性名称与数值、技能面板标题、各技能文字。
- Projects：模块标题、副标题，以及每张项目卡片的状态、标题、介绍和标签。
- Resume：模块标题、副标题，以及每段经历的时间、职位、公司、描述和亮点。
- Terminal：模块标题、副标题、窗口标题、开场提示、命令提示符、输入框提示。
- 页脚：结束标题、版权说明。

每条文字本身也是一个可折叠编辑项。摘要行显示中文名称和当前文案的截断预览；展开后显示：

1. 文案输入框；单行短文案使用文本框，多行介绍使用文本域。
2. 字体方案选择器。
3. 字号滑块与当前百分比。
4. “恢复此项默认值”按钮。

任一时刻只需要展开一个文字编辑项。切换选中项时，之前的输入已经实时保存，不需要额外的保存按钮。

### 页面选择与侧栏定位

- 编辑状态下，可编辑文字显示轻量像素虚线轮廓；当前选中文字使用更明显的高亮色。
- 点击页面文字时，不在页面原地输入，而是选中该文字。
- 侧栏自动展开文字所属模块与文字编辑项，并滚动到该编辑项；文案输入框获得焦点。
- 点击导航文字、项目卡片内文字或其他带跳转行为的文字时，编辑状态优先执行“选择文字”，不得触发导航或外链。
- 关闭侧栏后，这些元素恢复原有点击行为。
- 用户也可以完全不点击页面，直接在侧栏列表中找到并展开任意文字。

### 实时预览

- 文案输入框的每次 `input` 事件都立即更新页面对应文字、侧栏摘要预览和本地草稿。
- 字号滑块的每次 `input` 事件都立即更新页面对应文字及百分比显示。
- 字体下拉框变化后立即更新页面对应文字。
- 所有文案始终按纯文本处理，不解析 HTML。
- 输入框允许保存空字符串；页面对应文字可为空，但编辑项仍保留在侧栏，以便再次编辑或恢复默认。
- 浏览器原生撤销可用于输入框；持久化层不另外提供跨字段撤销历史。

## 字体与字号模型

每条文字拥有独立的字体方案和字号倍率。字号倍率范围继续使用 `80%–140%`、步长 `5%`，默认 `100%`。顶部全站字号滑块继续存在，两者叠加：顶部滑块控制整站可读性，工作台滑块控制某条文字相对于自身默认字号的比例。

四种字体方案保持不变：

1. `经典像素`：中文 Zpix；英文标题 Press Start 2P；英文正文 VT323。
2. `清晰终端`：中文 Zpix；英文文字 VT323。
3. `硬核街机`：中文 Zpix；英文文字 Press Start 2P。
4. `代码等宽`：中文 Zpix；英文文字 Fira Code。

字体方案应用在具体的可编辑元素上。中文仍使用 Zpix，方案主要决定英文显示字体；混合文案重新渲染后仍按中英文字符边界生成语言片段。每条文字的字号倍率通过元素级 CSS 自定义属性参与现有字号令牌计算，不使用 `transform: scale()`，避免影响清晰度、点击区域和布局测量。

## 数据结构与迁移

草稿继续使用 `localStorage` 键 `personal-site-studio-draft`，格式版本升级为 V2。核心结构为：

```json
{
  "version": 2,
  "text": {
    "hero.title": "岁安"
  },
  "textStyles": {
    "hero.subtitle": {
      "font": "terminal",
      "scale": 120
    }
  },
  "ui": {
    "selectedKey": "hero.subtitle",
    "openSections": ["hero"]
  }
}
```

- `text` 保存与源文案不同的纯文本草稿。
- `textStyles` 保存每条文字的字体和字号；未出现的编辑键使用该元素的源排版。
- `ui` 仅保存工作台导航状态，不影响网站内容。
- 编辑键必须已存在于当前页面且长度、文本长度、字体值、字号范围均通过校验，才允许应用。

升级时读取现有 V1 草稿：

- 原有 `text` 文案按相同编辑键保留。
- 原有某区域的字体或字号设置，复制为该区域当前所有文字的 V2 独立样式，使升级前后的视觉结果尽量一致。
- 不存在的区域、未知字体、非法字号和过长文案被忽略。
- 迁移成功后写回 V2；迁移失败时回退源页面，不阻止网站正常使用。

## 编辑项注册与命名

页面继续以 `data-edit-key` 作为文字与草稿之间的稳定身份。为了让侧栏生成可读名称，每个可编辑元素还要提供编辑标签和区域信息：静态文字可以写在 HTML 属性中，动态文字在 `js/script.js` 创建节点时注册。

侧栏在页面数据渲染完成后扫描所有编辑元素，按区域和 DOM 顺序生成列表。不能只维护一份手写侧栏 HTML，否则项目、技能或经历数量变化后容易漏项。动态列表重新生成时需要保留仍然有效的选中项。

对于项目、经历、技能等重复内容，标签包含对象名称或序号，例如“松绑 · 项目介绍”“第 1 段经历 · 公司”“Python · 技能文字”，避免出现多个无法区分的“标题”。

## 重置规则

- “恢复此项默认值”同时清除该编辑键的文案草稿和独立字体/字号，并恢复源页面文字与源排版。
- 每个区域保留“恢复本模块默认值”，一次清除该区域下全部文字的文案与样式草稿。
- “恢复全部默认值”只清除工作台 V2 草稿，不清除顶部全站字号偏好。
- 所有重置操作立即更新页面与侧栏；空字符串是有效草稿，不能被误判为需要恢复默认。

## 终端特殊处理

终端输入框的 `placeholder` 继续使用编辑键 `terminal.inputPlaceholder`，但不再借用真实终端输入框进行编辑。它与其他文字一样在侧栏中拥有独立文案输入框、字体和字号控制；实时预览只修改页面终端输入框的 `placeholder` 属性。

编辑状态下点击终端占位提示会定位侧栏编辑项，不执行命令。关闭工作台后，真实终端输入框恢复输入 `help`、`game` 等命令的能力。动态命令输出和小游戏 Canvas 不进入编辑清单。

## 可访问性与响应式

- 侧栏、区域和文字编辑项使用按钮或 `details/summary` 等原生可聚焦控件，并维护展开状态。
- 页面文字选择支持鼠标；侧栏本身提供完整键盘编辑路径，因此不要求页面文字额外进入 Tab 顺序。
- 当前选中项通过视觉高亮与 `aria-current` 或等效状态表达。
- 输入控件都有与可见中文名称关联的标签。
- 桌面端侧栏固定在右侧并独立滚动；页面本身仍可滚动。
- 小屏幕沿用底部面板布局，但同样只能由 `×` 关闭，最大高度受视口限制，内容区独立滚动。
- `prefers-reduced-motion` 下，侧栏自动定位使用即时滚动，不使用平滑动画。

## 异常与边界处理

- `localStorage` 不可用时，实时预览仍在当前页面有效，只是不跨刷新保存。
- 某编辑键对应元素不存在时，忽略该条草稿并继续初始化其他文字。
- 数据重新渲染产生新元素时，工作台重新扫描注册并重新应用现有草稿。
- 字体文件加载失败时沿用现有回退字体链。
- 侧栏文案输入不得通过 `innerHTML` 写入页面。
- 编辑状态关闭时清理页面选择高亮，但不清除草稿。

## 测试与验收

### 自动测试

- V1 草稿向 V2 的文案与区域样式迁移。
- V2 草稿校验、非法值回退和空字符串保存。
- 两条 Hero 文字可以拥有不同字体和字号，互不影响。
- 侧栏文案输入、字体选择和字号滑块实时更新对应页面元素。
- 点击页面文字只选择并定位对应侧栏项，不发生原地 `contenteditable` 编辑。
- 编辑状态下，外部点击和 `Escape` 不关闭侧栏；只有 `×` 关闭并恢复触发按钮焦点。
- 单项、模块和全部重置的作用域正确。
- 终端占位提示通过侧栏实时编辑，不干扰正常终端命令。
- 动态项目、技能与经历文字全部进入侧栏清单。
- 中英文重新分片、手机字号倍率、人物滚动切换和小游戏速度测试继续通过。
- 小游戏配置断言初始速度为 `1`、最高速度为 `2.5`。

### 浏览器验收

1. 打开编辑网站，点击页面空白、滚动和按 `Escape`，侧栏始终保持打开。
2. 点击 `岁安`，侧栏定位到 Hero 姓名；点击 `Data Analyst / AI Learner`，定位到 Hero 身份介绍。
3. 保持姓名不变，单独放大身份介绍，确认两者字号互不影响。
4. 在侧栏修改任意文案，确认页面逐字实时预览；刷新后草稿仍存在。
5. 检查导航、About 属性与技能、两个项目、三段经历、Terminal 和页脚均有独立编辑项。
6. 点击 `×` 关闭后，项目卡片能在新标签页打开 GitHub，导航和终端命令恢复正常。
7. 在桌面和手机宽度下确认侧栏/底部面板可滚动、无不可达控件。
8. 输入 `game`，确认小游戏从速度 `1` 开始且最高不超过 `2.5`。

## 定稿与移除

本阶段不把浏览器草稿自动写入源文件。岁安完成调整并明确要求定稿后，再读取 V2 草稿，将文案写回 `data.js`/`index.html`，将字体与字号写回永久样式，运行完整验收，然后删除工作台 UI、V2 控制器和草稿键。是否同步 GitHub仍由岁安单独明确指示。
