# 中英标题与 Songbang 图标

## 目标

- 中英混排项目标题保持统一的视觉高度，同时保留英文像素字体风格。
- 提供可复用的中文标题、英文标题和混排间距样式。
- Songbang 使用本地 SVG 像素风图标，不依赖浏览器 emoji 字体。

## 实现与验收

- 项目数据支持可选的英文标题字段与可选图片字段。
- 项目渲染为中文标题和英文标题分别输出语义化元素；只有中文标题的项目保持正常显示。
- CSS 以变量集中定义中英文标题的字体、字号比例、行高和间距。
- 新增 `assets/songbang-knot.svg`，Songbang 卡片显示该图标。
- 不改变卡片跳转、新标签页行为或其他项目内容。
- 仅创建本地提交，不推送个人网站仓库。
