# 个人网站定制器使用说明

## 启动

双击项目根目录的 `start-editor.cmd`。脚本会启动一个只监听本机 `127.0.0.1` 的服务，并打开编辑器。

- 编辑器：`http://127.0.0.1:4173/editor.html`
- 公开主页：`http://127.0.0.1:4173/`

不要直接双击 `editor.html`，因为正式保存、历史版本和素材上传需要本地服务。

## 编辑与保存

1. 从左侧选择模块、内容记录和具体文字，也可以直接点击中间预览中的文字。
2. 在右侧调整文案、字体、字号、颜色、对齐等属性。
3. 所有修改会即时出现在中间的真实页面中，并自动保留为本地草稿。
4. 草稿不会影响公开主页。确认后点击顶部“保存到网站”，正式配置才会写入 `site-config.json`。
5. “撤销”回到本次编辑的上一步；“放弃草稿”恢复最后一次正式保存的配置。

文案输入框支持直接换行。中英文字体可以分开选择，每个履历字段、项目标签和技能项也都有独立设置。

## 主题、素材与交互

- “主题”可以调整背景、卡片、文字、边框、强调色、扫描线、粒子和间距。
- “素材”可以替换 Hero 人物图、项目图标及自定义光标。
- “交互”可以调整打字速度、滚动切换阈值、粒子和动画开关。
- 顶部“桌面 / 手机”用于检查不同屏幕下的效果；手机预览宽度为 390px。

上传素材会保存在 `assets/custom`。光标只接受 PNG/CUR，其他图片接受 PNG/JPG/WEBP，并有文件大小限制。

## 小游戏

“游戏”页可以调整起始速度、最高速度、加速、跳跃和落地参数，以及障碍组合。

- 起始速度默认为 1。
- 最高速度硬限制为 2.5。
- 不可能通过的障碍组合会阻止正式保存。
- 点击“在页面终端即时试玩”，会在中间真实页面的终端区域启动独立试玩。

## 历史版本

每次点击“保存到网站”之前，旧配置都会自动备份。编辑器保留最近 20 个版本，可在“历史”页恢复。备份位于 `.site-studio/history`，不会提交到 Git。

## 旧版草稿迁移

1. 打开编辑器左下角的“旧版导出工具”。
2. 下载浏览器中原有的 `personal-site-studio-draft`。
3. 回到编辑器，点击“导入旧版草稿”并选择刚下载的 JSON。
4. 检查迁移后的文案和字体，再点击“保存到网站”。

## Git 说明

编辑器不会执行 Git 命令。网站开发仍以本地仓库为准；只有明确要求同步 GitHub 时，才进行远程推送。
